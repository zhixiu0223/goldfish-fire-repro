## 摘要 (Abstract)

一道經典腦筋急轉彎題(「密閉無窗房間發生猛烈火災,把所有家具燒成灰燼,水缸裡的金魚是死是活?」)被當作起點,嘗試轉譯成一個可計算的工程問題:**在哪些物理條件下,金魚的死因由「熱」主導、由「缺氧」主導,或兩者皆非?**

我們建立了一個 0D 集總參數常微分方程(ODE)模型,耦合房間氣體能量/氧氣平衡、水缸熱傳(輻射+對流)、水中溶氧動態(溫度相依亨利定律近似 + Q10 代謝耗氧)。透過參數敏感度掃描與時間歷程分析,得到以下**定性結論**:

1. 在所有測試參數組合中,**熱死機制從未被缺氧死機制反超**——水溫達到致死線,幾乎總是先於或同時於溶氧降到致死線。
2. **牆體邊界熱損失是否存在(而非牆體材質本身)**,是目前模型中槓桿效應最大的假設——從「近乎絕熱」切到「文獻校準的暫態熱傳導」,存活/死亡結論可以整個翻轉。
3. 一旦採用任何合理的建材(石膏板單層/雙層、混凝土),彼此間造成的結果差異遠小於「有無散熱」這個二元選擇本身。

**本文件的性質是一份誠實的研究過程記錄,不是已驗證的工程結論**——見下方「限制與未完成事項」一節。所有數值結果的絕對量級都不應被直接引用,只有機制層級的定性排序(哪個死因先發生、哪個係數敏感)相對穩健。

## 1. 動機與問題轉譯

原始問題是一道網路流傳的腦筋急轉彎,不同大型語言模型(Gemini、DeepSeek、Grok、ChatGPT 等)對其給出不一致的答案(「活」或「死」或「無法判定」),且部分回答在思維鏈(Chain-of-Thought)提示下反而用捏造的數字包裝了錯誤結論。這個觀察促成了一個轉念:與其爭論唯一正確答案,不如把題目改寫成一個**參數化的工程問題**:

> 在密閉空間火災中,水缸內魚類的死亡是由哪些物理機制主導?其死因在不同房間尺寸、火災規模、水缸-火源距離、水缸材質/牆體構造下,是否存在明確的相變邊界(phase transition)?

## 2. 方法 (Methods)

### 2.1 模型結構

狀態變數:房間氣溫 $T_{room}$、房間氧氣體積分率 $O_{2,frac}$、累積燒掉燃料量 $m_{burned}$、水缸溫度 $T_{water}$、水中溶氧濃度 $DO$。

### 2.2 使用的物理關係式與其文獻出處

| 機制 | 公式/方法 | 出處/性質 |
|---|---|---|
| 火災成長 | $\dot Q = \alpha t^2$ (ultra-fast, $\alpha=0.1876$) | 消防工程標準 t² 火災成長分類 |
| 氧氣消耗 | Thornton's rule, 13.1 MJ/kg O₂ | 氧耗量熱法(cone calorimetry標準常數) |
| 氧氣濃度對火勢的回饋 | 熄滅門檻 12–21% 間線性軟衰減 | 自訂簡化,無直接文獻式,取常見引用門檻範圍 |
| 輻射傳熱 | 點源模型 $q''=\chi_r \dot Q/(4\pi R^2)$ | 火災工程標準"點源輻射"近似,常用於防火間距估算 |
| 對流傳熱 | $q=h_{conv}A\Delta T$ | 通用牛頓冷卻定律,$h_{conv}$ 為概估常數 [**未校準**] |
| 牆體熱損失 | 半無限固體暫態傳導 $h_k(t)=\sqrt{k\rho c/(\pi t)}$ | Drysdale (1999) *An Introduction to Fire Dynamics*, 材料 $k\rho c$ 標準表 |
| 水中溶氧飽和度 | $DO_{sat}(T)=14.6-0.41T+0.005T^2$ | 常見淡水溶氧-溫度經驗擬合式 |
| 魚呼吸耗氧 | Q10 溫度效應 + Monod飽和動力學 | 通用生理學/生化動力學框架,係數為概估 [**未校準**] |

### 2.3 求解方式

`scipy.integrate.solve_ivp`(RK45),單一 Python 實作,無其他數值方法或工具交叉比對。

### 3.1 疊代修正歷程(誠實記錄,而非隱藏)

本分析刻意保留每一次「發現模型輸出違反直覺 → 回頭檢查模型假設 → 找到結構性簡化錯誤 → 修正 → 結論可能整個翻轉」的疊代過程,而非只呈現最終版本:

1. **v1**:房間體積 × 水缸-火源距離相圖,發現對流傳熱項不隨距離衰減(結構性缺陷:單一均溫房間假設抹平了真實的熱氣層分層效應)
2. **v2/v3**:拉長模擬時間至10小時,發現(a)溶氧被扣為負值(耗氧項未設下限)(b)牆體無外部散熱路徑,長期人為收斂到不合理高溫平衡
3. **v4**:改用半無限固體暫態熱傳導取代拍腦袋的 $UA_{ext}$,發現結果整個翻轉(多數案例從死轉為存活),且該公式本身只在特定時間窗內成立(單層石膏板僅2.4分鐘)
4. **v5**:牆體材質(石膏板單層/雙層/混凝土)敏感度測試,發現材質間差異遠小於「有無散熱」這個二元選擇本身(平方根關係壓縮了材質差異)

## 4. 限制與未完成事項 (Limitations — 本節為本文件最重要的部分)

- **無獨立交叉驗證**:所有結果來自單一 Python/scipy 實作,從未與第二個獨立工具(如 NIST CFAST 兩區模型、FDS CFD)比對。無法排除實作邏輯或公式套用本身存在系統性錯誤且未被發現的可能。
- **無實驗/實測數據比對**:未與任何真實火場記錄、消防工程量測數據做校驗。
- **多個關鍵係數未校準**:$h_{conv}$、$\chi_r$、$kLa$、魚類 Q10/耗氧基準速率,均為概估值,部分僅做過"倍率敏感度測試"而非真正的文獻校準。
- **空間結構被過度簡化**:單一均溫房間假設(0D)已知會扭曲對流傳熱的距離依賴性(見v1發現);真正需要至少 two-zone 模型(如 CFAST 的方法論)才能合理處理熱氣層分層。
- **火災動力學本身是開環的**:目前的 $\dot Q(t)$ 成長曲線不會因房間通風/氧氣供應而真正改變其成長型態(僅有硬性的濃度軟衰減上限),真實的通風控制轉換(ventilation-controlled combustion)機制未被實作。
- **半無限固體假設的失效時間未被完整處理**:超過材料厚度對應的穿透時間後,目前僅用權宜的「凍結」處理,非嚴謹解法。

## 5. 可能的下一步

1. 用 NIST CFAST(開源、公開領域,`github.com/firemodels/cfast`)重建同樣的房間/水缸/火源幾何,做真正的獨立交叉驗證
2. 改用有限厚度平板暫態熱傳導(取代半無限固體假設),或直接上一維/二維FEM
3. 無因次分析,嘗試把控制參數收斂成少數幾個 $\Pi$ 群
4. 若確認需要空間解析度(如水缸相對熱氣層/火羽流的位置),再上 FDS 等級的CFD
